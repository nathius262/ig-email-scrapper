# ig-email-scrapper

IG Email Scraper is a lightweight Python tool built to scrape publicly available email addresses and contact data from Instagram profiles. Designed for lead generation and outreach workflows, it helps users quickly collect potential business contacts from public Instagram accounts and export the results in a clean, usable format.

Whether you’re building a sales pipeline, running outreach campaigns, or researching leads, IG Email Scraper makes it easier to gather contact information efficiently from public profile data.
